# 运行说明

## 一、你的项目在哪

```
parking-detection\
├── code\          ← 程序在这里
│   ├── main.py            入口
│   ├── config.yaml        所有参数（权重、阈值、禁停区…）
│   ├── 运行_演示视频.bat   ← 双击这个看效果
│   ├── 运行_自己的视频.bat ← 把自己的视频拖到这个图标上
│   ├── 运行_摄像头.bat     ← 双击调用摄像头
│   ├── src\               8 个核心模块
│   ├── weights\           模型权重
│   ├── configs\           禁停区多边形
│   ├── samples\           测试视频
│   └── outputs\           截图与日志输出
├── data\          数据集（640 张 + 说明）
└── docs\          文档
```

## 二、三种运行方式（都不需要敲命令）

### ① 看效果（推荐先跑这个）

双击 **`code\运行_演示视频.bat`**

- 用的是 `samples\parking_demo.mp4`（合成画面：橙色块代表自行车驶入禁停区停 12 秒）
- 30 秒内能看到：检测框 → 橙色"入侵"告警 → 8 秒后红色"违停"告警
- 按 `Q` 或 `ESC` 退出

### ② 跑自己的视频

把视频文件**拖到** `code\运行_自己的视频.bat` 图标上松手

- 支持 mp4 / avi / mov
- 会额外导出标注视频到 `outputs\annotated.mp4`

### ③ 摄像头实时

双击 **`code\运行_摄像头.bat`**

- 调用默认摄像头（编号 0）
- 适合把笔记本/手机摄像头对着电动车拍

## 三、跑完看什么

`code\outputs\` 目录：

| 文件 | 内容 |
| --- | --- |
| `screenshots\alarm_*.jpg` | 每次告警的截图（带框、区域、横幅） |
| `alarms.csv` | 告警日志（时间、事件类型、类别、停留时长、截图名） |
| `annotated.mp4` | 叠加了检测框的视频（用 `--save-video` 时生成） |

## 五、常用参数（改 config.yaml，或用命令行）

| 需求 | 做法 |
| --- | --- |
| 调停留判定时长（默认 8 秒） | `config.yaml` → `judge.dwell_seconds` |
| 调检测灵敏度（默认 0.35） | `config.yaml` → `model.conf`，越低越灵敏 |
| 只报"进入即告警"，不要违停判定 | `judge.mode: "intrusion"` |
| 换禁停区形状 | 改 `configs\roi.json`，或 `python main.py --make-roi 1280 720` 交互式点选 |
| 换微调模型（中文场景更准） | `config.yaml` → `weights: weights/ebike_scene_finetuned.pt`，并把 `class_ids` 改成 `[0]` |

## 六、常见问题

| 现象 | 原因与解决 |
| --- | --- |
| 双击 bat 一闪就没了 | 看报错内容；多半是找不到 `D:\cv_data\venv`，按第四节重建 |
| 窗口里没有画面 | 检查视频路径；或改用 `--no-window` 跑（无界面模式） |
| 一直不告警 | 画面里没有非机动车 / 车没进禁停区 / `judge.mode` 设置不对 |
| 提示 cv2 报错 | OpenCV 版本问题，`pip install opencv-python==4.10` |
| 中文变成方块 | 系统缺微软雅黑字体（Windows 一般自带） |

## 七、也可以直接敲命令（在 `code` 目录下）

```powershell

D:\cv_data\venv\Scripts\activate

python -m unittest discover -s tests -v
```

## 八、网页演示版（推荐演示用）

双击 **`code\启动_网页演示.bat`**，浏览器会自动打开 <http://127.0.0.1:8123>

关闭那个黑色命令行窗口即停止服务。

### 页面怎么用（四步）

| 步骤 | 操作 |
| --- | --- |
| ① 选择视频源 | 点示例视频卡片，或点「上传本地视频」选自己的视频 |
| ② 设置参数 | 拖动置信度、停留时长，选告警模式与检测模型（也可点「随机参数」） |
| ③ 运行检测 | 点「开始检测」，可看到五段 pipeline 依次点亮 + 进度条 + 实时预览画面 |
| ④ 查看结果 | 统计卡、告警时间线、取证截图（点击放大）、标注视频、CSV 下载 |

### 两个便捷参数

| 链接 | 作用 |
| --- | --- |
| `http://127.0.0.1:8123/?autorun=1` | 打开就自动跑一次示例视频 |
| `http://127.0.0.1:8123/?job=<任务ID>` | 直接展示某一次的历史结果 |

### 禁停区怎么定（每个视频可以不一样）

禁停区不是写死在程序里的，它是一份**归一化坐标的多边形**（`configs/roi.json`），
所以：

| 情况 | 行为 |
| --- | --- |
| 选示例视频 | 自动加载该视频的默认区域（如 `scene_demo` 对应右侧停放的 `lot_scene`） |
| 上传自己的视频 | **没有默认区域，需要你画**（否则用兜底的 `lot_A`，可能对不上画面） |
| 网页上自己画 | 在 ② 步骤的画面里点击加点，≥3 个点即生效，**优先级最高** |

**画法**：在画面上依次点击顶点 → 自动连成多边形（半透明黄色填充）
- 右键或「撤销顶点」删掉最后一个点
- 「清空」重新画
- 「用默认区域」恢复该视频自带的区域
- 「全画面」把整个画面设为禁停区

坐标是**归一化**的（0~1），所以同一个多边形在不同分辨率的视频上都能用；
换成 4K 摄像头也不用重画。

### 两个示例视频怎么选

| 视频 | 内容 | 该选哪个模型 | 结果 |
| --- | --- | --- | --- |
| `scene_demo.mp4` | **真实照片**合成的固定机位监控（一排共享电单车），推荐 | COCO 预训练（默认） | 检出 4 辆车，框内红色「违停」、框外绿色不告警 |
| `parking_demo.mp4` | 纯色块合成的链路测试视频 | 演示模式（合成画面色块） | 验证流程用，画面是色块不是真车 |

页面会自动帮你选：选 `scene_demo` 用 COCO 模型，选 `parking_demo` 自动切到演示模式。

### 每次结果为什么不同

- 参数不同（置信度、停留阈值）→ 检出数量与告警时机不同
- 点「随机参数」可一键随机化，便于对比不同阈值的效果
- 换不同视频 → 结果完全不同

### 服务端口被占用怎么办

改 `code\web\server.py` 最后一行的 `port=8123`，同时改 `启动_网页演示.bat` 里的地址。
